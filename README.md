# Git 远程分支演练项目 (Pro Git 3.5)

本项目用于演练《Pro Git》第 3.5 节“远程分支”中的核心概念与操作。

## 演练目标
1. 远程跟踪分支（`origin/master`、`origin/<branch>`）的只读特性与移动规律。
2. 分支推送与映射（`git push origin <branch>` 与 `git push origin <local>:<remote>`）。
3. 跟踪分支（`git checkout --track`、`git checkout -b <branch> origin/<branch>`、`git branch -u`）。
4. 状态观察（`git branch -vv` 观察 `ahead` / `behind` 状态）。
5. 同步与合并（`git fetch` vs `git pull`）。
6. 删除远程分支（`git push origin --delete <branch>`）。
